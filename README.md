# Catching Game

![Preview](/public/img/previews/light.webp)

Catch all the falling treasures while avoiding the enemies walking across the field. Watch out for the anvils and only collect the acorns. Be carful of your health! Avoiding taking to many hits from the enemies and anvils or you will be out.

## Getting Started

First you will need to setup a .env file from the .env.sample provided.

Then development server can be run:

```bash
npm run dev
```

# Controls
✅ Keyboard Support
⚠️ Controller Support
✅ Touch Support (via joystick and click to move)

## Scripts

In the scripts folder is reset_public and sync_to_s3. This is only for Articles Media usage. Allows for putting public folder to CloudFront to lower Vercel charges for the public facing site.

## Multiplayer

Play with up to 8 other friends and compete to get the best score. Multiplayer is handled through Socket.IO via Websockets. Backend code is not in this repo or available at this time.
